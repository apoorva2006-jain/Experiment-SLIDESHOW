# Experiment-SLIDESHOW
Aim

To develop an Android application that displays a slideshow of images automatically at regular intervals.

Algorithm

1. Open Android Studio.


2. Create a new Android project.


3. Open activity_main.xml file.


4. Add an ImageView control to display images.


5. Store images in the drawable folder.


6. In MainActivity.java, declare an ImageView variable.


7. Create an array to store image resources.


8. Declare a Handler object for timing.


9. Create a Runnable method for slideshow logic.


10. Display image using setImageResource().


11. Increase image index after displaying each image.


12. Reset index when it reaches the end of the array.


13. Use postDelayed() to change image every few seconds.


14. Start the slideshow in onCreate().


15. Stop the slideshow in onDestroy().


16. Run the application and observe images changing automatically.
